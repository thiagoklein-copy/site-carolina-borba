# Carolina Borba — site institucional

Next.js (App Router) + TypeScript + Tailwind CSS + Framer Motion.
Deploy: Vercel.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Contatos centralizados
